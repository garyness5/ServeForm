Savveyra v0.1.72_AddressBook_Normalized

Address Book
------------
• Completed normalization of CustomerList, ContactList and VenueList.
• Standardized page architecture across all three Address Book domains.
• Standardized widget naming and modal naming.
• Renamed JS objects to jsCustomer and jsCustomerContact.
• Removed obsolete toggleStatus() JS procedures.
• Moved Active status updates to table onCheckChange handlers using parameterized queries.
• Eliminated cyclic dependency caused by table callbacks through JS objects.
• Added client_id protection to Customer Contact link queries.
• Updated deleteCustomerContactLinks to delete only current client records.
• Standardized duplicate checking behaviour.
• Standardized Save, Save & New, Duplicate, Delete and Cancel workflows.
• Standardized quick Contact Add behaviour from Customer.
• Standardized Active filter defaults to "All" across Customer, Contact and Venue pages.
• Removed obsolete and duplicate queries.
• Added delete button loading protection on destructive confirmation dialogs.
• Performed general cleanup and consistency review across Address Book.

Result
------
Address Book is considered functionally complete for the current phase and is parked pending downstream Event integration. Future changes are expected to be minor adjustments driven by Events, Proposal and Quotation workflows.
